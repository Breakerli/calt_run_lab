# template.docx 文档分析报告

本文档分析 `docs/template.docx`（机器人奔跑初训练与验证报告模板）的结构与内容，明确生成该类报告所需准备的全部数据与信息。

## 一、文档概述

- **报告主题**：RYP01-v2 机器人（13 自由度）奔跑初训练与 Sim2Sim 验证
- **技术流程**：IsaacLab 策略训练 → MuJoCo Sim2Sim 验证（两阶段）
- **验证目的**：在独立动力学引擎中复现高速奔跑工况，记录关节位置、角速度、输出转矩及功率数据，为关节载荷分析与电机选型提供依据
- **示例工况**：前向速度指令 10 m/s；统计窗口为 2 个完整步态周期，共 66 个 100 Hz 策略步采样点

### 3.3.2 仿真结果分析

共 4 组分析，每组包含：7 类关节的时序曲线图（左右同类关节同图、同纵轴范围）+ 1 张统计表 + 一段"主要结果"结论。峰值均按时间窗内绝对值最大值统计。

#### 1. 转速-时间曲线（图 1–7）

统计表字段：关节 / 峰值转速 / 理论转速 / RMS 转速 / 理论 RMS 转速（单位 rad/s）。

- 结论示例：绝对峰值转速最高为右踝 Pitch 26.242 rad/s（250.6 rpm）；RMS 转速最高为左肩 Pitch 15.087 rad/s（144.1 rpm）。

#### 2. 转矩-时间曲线（图 8–14）

统计表字段：关节 / 峰值转矩 / 理论峰值转矩 / RMS 转矩 / 理论 RMS 转矩（单位 N·m）。

- 结论示例：绝对峰值转矩最高为左髋 Pitch 293.102 N·m；RMS 转矩最高为右髋 Pitch 190.738 N·m。

#### 3. 功率-时间曲线（图 15–21）

机械功率按 P = τ × q̇ 计算；正值表示驱动输出机械能，负值表示制动或潜在能量回馈。

统计表字段：关节 / 绝对峰值功率 / 理论峰值功率 / RMS 功率 / 理论 RMS 功率（单位 W），需同时统计正、负峰值。

- 结论示例：最大正功率、绝对峰值功率和 RMS 功率均出现在右髋 Pitch（3513.8 W / 3513.8 W / 1540.3 W）；最大负功率出现在右膝 Pitch（−2863.3 W）。

#### 4. 转速-转矩包络曲线（图 22–28）

蓝色轨迹为仿真关节工作点；橙色虚线与浅色区域为电机曲线按四象限对称扩展后的能力包络。

统计表字段：关节 / 最大包络利用率 / 包络外样本数。

- 结论示例：13 个关节共 858 个工作点均位于包络内；最高利用率为左髋 Pitch 74.7%。
- 注意：该结论仅表示瞬时工作点满足包络，最终选型仍需结合额定连续转矩、热容量、减速比、效率和母线电压。

## 三、生成报告所需准备的信息清单

### 1. 仿真采样数据（核心）

- 13 个关节在统计窗口内的**关节位置、角速度、输出转矩**时间序列（100 Hz 采样）
- 统计窗口需覆盖 ≥2 个完整步态周期（示例为 66 个采样点）
- 前向速度指令值及 Sim2Sim 工况描述

### 2. 机器人模型参数

- URDF/XML 模型：各刚体质量（用于总质量求和）、关节配置
- 默认站姿关节角度、初始基座高度
- 各类关节的 PD 增益（Kp、Kd）与输出侧转矩/速度限值

### 3. 训练配置

- 观测维度构成、动作维度、历史观测长度
- 指令范围与课程学习速度扩展设置

### 4. 理论参考值

- 各关节的理论转速、理论转矩、理论功率（统计表中"理论"列，来自设计指标或经验公式）
- 左右对称关节可只给一侧理论值（示例中右侧为"—"）

### 5. 电机能力包络数据

- Excel 形式的电机转速-转矩曲线（按四象限对称扩展）
- 用于计算包络利用率与包络外样本数
- 后续选型还需：额定连续转矩、热容量、减速比、效率、母线电压
